# Ways of Tuning｜DVC 站台說明

這是 DVC 站台使用的互動照片調色遊戲。畫面會把本地照片切成多條色彩影像，玩家透過移動角色及調整色相、飽和度與亮度，讓切片逐步接近原圖。預設目標為每條切片達到 95% 相似度。

遊戲可用鍵盤操作，也可連接 Arduino 按鈕控制台。遊戲畫面與後台控制頁可在同一部電腦或同一區域網路內的不同電腦使用。

## 遊戲模式

- **模式 1**：兩位玩家調整色彩；閒置時各切片會播放色彩動畫。
- **模式 2**：在模式 1 的基礎上，各切片以不同速度擺動色彩，即使玩家正在操作也會繼續。
- **模式 3**：四位玩家共同操作。畫面分成上下兩排共 16 條短切片，中央保留一條長切片；短切片持續浮動，不因玩家操作停止。芝士圖示在上排靠上、下排靠下，中央長切片的芝士圖示亦靠底對齊。色相循環變化，飽和度與亮度在範圍端點反向。

閒置 15 秒後會播放動畫，適用於所有模式。遊戲計時在首次遊戲操作後開始；之後每 5 分鐘自動升一個模式，最高為模式 3。按 `1`、`2` 或 `3` 可手動選擇模式。

玩家移動時會播放各自不同的提示音；完成切片取得芝士時，會播放快速的高音雙聲提示音；完成整張照片時則播放提示音。

可在網址以秒數覆寫這兩個時間，方便測試；省略參數時使用上述預設值。例如 `http://127.0.0.1:5174/?idleSeconds=3&levelUpSeconds=30` 會在閒置 3 秒後播放動畫，並每 30 秒自動升級。

## 鍵盤操作

| 玩家 | 移動 | 色相 | 飽和度 | 亮度 |
| --- | --- | --- | --- | --- |
| P1（Mouse） | `←` / `→` | `O` / `L` | `P` / `;` | `[` / `'` |
| P2（Hamster） | `A` / `D` | `R` / `F` | `T` / `G` | `Y` / `H` |

上表按鍵依序代表增加／減少。模式 3 的操作配置如下：

| 玩家 | 移動 | 色相 | 飽和度 | 亮度 |
| --- | --- | --- | --- | --- |
| P1（Hamster，左下） | `←` / `→` | `O`（增加） | `P`（增加） | `[`（增加） |
| P2（Mouse，右下） | `A` / `D` | `R`（增加） | `T`（增加） | `Y`（增加） |
| P3（Dog） | `↑` / `↓` | `L`（減少） | `;`（減少） | `'`（減少） |
| P4（Bug，右上） | `W` / `S` | `F`（減少） | `G`（減少） | `H`（減少） |

其他快捷鍵：

- `C`：開啟或關閉搖桿設定。
- `Q`：自動調整。
- `Space`：前往下一回合。

## 啟動遊戲

需要安裝 Node.js。於專案資料夾執行：

```bash
npm start
```

Windows 也可執行 `start.bat`；它會啟動本機伺服器，並嘗試以全螢幕開啟 Chrome。

- **遊戲畫面**：<http://127.0.0.1:5174/>
- **後台控制**：<http://127.0.0.1:5174/backstage>

後台可查看目前回合、計時與配對進度，並控制開始或切換回合。若在其他電腦操作，請使用後台顯示的區域網路網址；遊戲主畫面需在展示用電腦開啟。

## Arduino 搖桿設定

遊戲可不連接搖桿，直接使用鍵盤操作。連接 Arduino 時，請使用支援 Web Serial 的 Chrome 或 Edge，並透過 `localhost` 開啟遊戲：

1. 在遊戲畫面按「Allow joystick」，並允許瀏覽器存取序列埠。
2. 按 `C` 開啟設定，依提示逐一按下實體按鈕；不使用的控制可略過。
3. 設定頁可匯出或匯入 JSON。預設腳位對應在 [`joystick-setup.json`](./joystick-setup.json)；瀏覽器也會保留目前的對應設定。

模式 3 中，舊 P1 搖桿控制左下的 P1（Hamster）及左上的 P3（Dog）；舊 P2 搖桿控制右下的 P2（Mouse）及右上的 P4（Bug）。Up/Down 控制 P3/P4 移動；搖桿的 X/Y/Z 按鈕調整 P1/P2，A/B/C 按鈕調整 P3/P4。若已為 P3 或 P4 個別設定搖桿按鈕，個別設定優先。

此控制台使用兩塊 Arduino：主板透過 USB 序列埠與遊戲通訊，並經 I²C 向從板讀取按鈕。接線、腳位與序列資料格式請參閱 [`arduino_console/README.md`](./arduino_console/README.md)。

## 後台與 OSC

後台頁面可設定送出的 OSC 主機與連接埠；未填主機時不傳送。DVC 站台預設亦在 UDP `9030` 接收 OSC：

- `/dvc/black`：大於 0 時隱藏畫面並關閉聲音；傳送 0 可恢復。
- `/dvc/start`、`/dvc/reset`、`/dvc/restart`：控制遊戲流程；數值至少為 `0.5` 時觸發。
